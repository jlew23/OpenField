# Knowledge folder

Drop your copy of **THE RAP WRITING BIBLE** here as a markdown file whose name contains
"bible" (for example `RAP-WRITING-BIBLE.md`), or upload it from the Academy page.

Your Bible is personal: `*.md` files in this folder are git-ignored so they never get
pushed to a public repo. The Academy reads the levels, chapters, drills, graduation
tests, daily routines, skill ladder and appendices straight from it.
